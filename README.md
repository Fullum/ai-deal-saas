# DealSense AI

AI-powered SaaS for smart deal scoring and marketplace price analysis.

## Overview

DealSense AI is a multi-marketplace analysis platform designed to detect good deals, estimate real market prices, and provide intelligent product scoring using AI-powered analytics.

## Features

- Smart deal scoring
- Marketplace price analysis
- Product evaluation system
- Historical price tracking
- AI-driven analytics
- Multi-marketplace integration
- Future eBay API support
- SaaS-ready architecture

## Tech Stack

- Python
- Flask
- SQLite
- HTML/CSS/JavaScript
- REST API

## Vision

The goal of DealSense AI is to become an intelligent assistant for buyers, resellers, and marketplace users by analyzing listings across multiple platforms and identifying the best opportunities automatically.
